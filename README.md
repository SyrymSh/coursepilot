# CoursePilot 0.2.10

Расширение Chrome: 50 часов / 25 календарных дней на предмет. Курсы одного предмета делят общий бюджет; до четырёх предметов работают параллельно.

## Установка и обновление

1. Распакуйте ZIP. В Chrome 120+ откройте `chrome://extensions` и включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`: `extension` либо `dist/coursepilot`.
3. При обновлении замените файлы в той же папке, перезагрузите CoursePilot и обновите вкладки Coursera. Расширение не удаляйте — это сохраняет настройки и прогресс.
4. Каждый участник использует свой профиль Chrome и аккаунт Coursera. Chrome и компьютер должны оставаться включёнными.

## Настройка

- Добавьте готовую программу или ссылку Coursera, проверьте список курсов и нажмите «Запустить».
- Задайте расписание и часовой пояс; по умолчанию `Asia/Qyzylorda`, 09:00–21:00.
- Автопропуск ручных материалов включён; его можно выключить в настройках. Пропуски сохраняются со ссылками в карточке предмета.
- Для ИИ укажите полный `chat/completions` URL, модель и свой ключ. HTTPS либо HTTP на localhost; ключ вводится отдельно от URL.
- «Автоответы в диалогах Coach», автоотправка тестов и автогалочка Honor Code включаются отдельно. По умолчанию они выключены.
- Сохранённый ключ не показывается. Пустое поле сохраняет прежний ключ; удалить его можно отдельной опцией. Подписка Coursera не оплачивает сторонний API.

## Как работает

- Видео: без звука, 1×, возобновление паузы, переход после окончания. Известные поздравления закрываются, встроенные необязательные вопросы пропускаются через Skip.
- Coach: Start Dialogue нажимается один раз при включённых ИИ и автоответах, затем выполняются текстовые ответы. Черновики сохраняются; Try again не нажимается. Переход — после подтверждённого завершения.
- Тесты: поддерживаются распознанные radio/checkbox-вопросы. С включённой автоотправкой выполняются одна отправка и один финальный Submit; переход — после явного успешного результата.
- Инфографика Explore: Keep organizations secure: шесть меток → Mark as completed → подтверждение Completed → следующий материал, без ИИ.
- Ручные материалы: чтение, лаборатории, неизвестные форматы и задания с выключенной автоматизацией → список пропусков → следующий материал, в том числе через границу модулей. Без отметки Completed, оценки или добавления часов. Окно Start new attempt? закрывается через Cancel без расходования попытки. Черновик, неизвестное окно или отправленная попытка не покидаются автоматически.
- Временные ошибки API и видео допускают два дополнительных повтора. Ошибки авторизации, доступа и хранилища останавливают только соответствующий предмет.

Календарь начинается с первой зарегистрированной активности; день 25 — дата начала + 24 дня. Ориентир — 2 часа в день на предмет. Часы, календарь и завершение курсов учитываются отдельно. Перемотка, простой и сон не создают часы; при исчерпании бюджета автоматические действия останавливаются. Чтение запускается вручную и учитывается в активной вкладке с недавними действиями.

По умолчанию: 40 запросов ИИ в день, 800 токенов ответа, 12 автоответов Coach (настраивается 1–30), кэш до 60 ответов / 24 часов. Повторы расходуют ту же квоту. Провайдер получает вопросы и до шести последних пар реплик Coach. Ключ хранится локально, не в зашифрованном сейфе; в журнал и экспорт не входит. Общего сервера и общего ключа нет.

Пропущенные задания остаются незавершёнными и могут мешать получению сертификата. CAPTCHA, вход и оплата останавливают предмет. Honor Code отмечается только при отдельном включении опции и распознанном тексте. Расширение не изменяет сертификаты, оценки или даты; 50 часов / 25 дней не гарантируют перезачёт. Окно подачи 2–9 ноября 2026 года предварительное и меняется в настройках.

## Разработка и проверка

Node.js 22+, без установки зависимостей:

```powershell
npm test
npm run check
npm run package
npm run debug:browser
```

Последняя команда выводит адрес локального стенда; остановка — Ctrl+C. Сценарии используют имитацию API и не отправляют реальные задания. Они не заменяют проверку установленного обновления на Coursera.
