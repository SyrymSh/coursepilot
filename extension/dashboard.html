OpenAI-совместимый chat/completions endpoint. Для локального сервиса разрешён HTTP на localhost.

Одна отправка на попытку; переход дальше — только после явного успешного результата Coursera. Для распознанного Honor Code есть отдельная настройка ниже; остальные подтверждения остаются ручными.

По умолчанию выключено. При включённой автоотправке отмечает только распознанное «I, …, understand and agree» в блоке Honor Code. Это подтверждение от вашего имени: отправляемая работа является вашей. Неизвестный или изменённый текст, другие соглашения и проверка личности остаются ручными.

Отдельная опция, по умолчанию выключена. Текущий вопрос и до 6 последних пар «вопрос — ответ» передаются выбранному API-провайдеру; размер ограничен. Черновик не заменяется. Неизвестная форма, подтверждение или достигнутый лимит останавливают диалог; кодекс чести и проверка личности требуют ручного действия.

Без ИИ продолжаются расписание, видео и навигация. Задания, которым нужен ИИ или отдельный обработчик, ждут действия.
